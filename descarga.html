06 — Descarga e instalación

Obtén Himnario IEP para Pianistas

La aplicación está alojada en MediaFire. El archivo disponible actualmente tiene un tamaño aproximado de 2,5 MB y se distribuye para Android.

DESCARGAR DESDE MEDIAFIRE
¿Funciona sin internet?
La aplicación está pensada para utilizar sus funciones locales sin conexión. Las funciones o contenidos que dependan de servicios externos pueden requerir internet.
Instalación

Cómo instalar

Descarga

Abre el enlace de MediaFire y descarga el archivo disponible.

Extrae

Si recibes un ZIP, ábrelo y localiza el archivo APK.

Instala

Abre el APK y sigue las instrucciones de Android para instalarlo.

Comienza

Abre Himnario IEP para Pianistas y conoce sus herramientas.
